# Typewritter Simulator

A simple and clean web app for authors who dislike the chaos of other writing techniques.
Here, nothing to distract you from your task.

The page can be exported as a plain LaTex to be decorated later.

---

**SYNTAX**

    # Title            → \section*{}
    ## Subtitle        → \subsection*{}
    ### Smaller        → \subsubsection*{}
    > a quote          → quote environment
    (blank line)       → new paragraph
    Enter              → new line starting with an indent (checkbox "indent");
                         Backspace removes the whole indent
    *italic*  **bold**
    ---  or  * * *     → scene break
    "quotation"        → « quotation » (French) or “quotation”
    @title My title    → \maketitle (also @author, @date)
    % a comment        → LaTeX comment (line shown in blue, not typeset)
